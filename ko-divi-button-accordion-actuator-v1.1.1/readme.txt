Opens a specific Divi accordion toggle when a Divi Button module with actuator classes is clicked.

== Setup ==

1. Install and activate the plugin.
2. In the target accordion item body, add:
   <span id="official-rules-actuator" style="display:block;"></span>
3. On the Divi Button module, add these classes:
   ko-accordion-actuator ko-target-official-rules-actuator
4. Leave the Button Link URL empty.
5. Clear Divi/static/server/CDN cache.
